# Grammar Lab

Інтерактивний тренажер з граматики англійської мови: теорія українською + 5 типів вправ,
фільтр за рівнем учня, збереження прогресу в браузері.

## Структура

```
index.html        — розмітка сторінки + підключення скриптів
js/engine.js      — рушій: рендер, перевірка відповідей, прогрес, фільтр рівнів
data/<тема>.js    — навчальний контент, по одному файлу на тему
```

Контент і рушій розділені. Щоб додати тему, рушій чіпати не треба.

## Як додати нову тему

1. Створити файл `data/<id>.js`, де `<id>` — англійський ідентифікатор теми
   (`modal-verbs`, `past-tenses`, `conditionals`).
2. Вміст файлу:

```js
window.TOPICS_DATA = window.TOPICS_DATA || {};
window.TOPICS_DATA["modal-verbs"] = {
  id: "modal-verbs",
  title: "Модальні дієслова (Modal Verbs)",
  description: "Короткий опис українською",
  theory: [ /* блоки теорії */ ],
  exercises: { order: [], choice: [], gap: [], cross: [], abcd: [] }
};
```

3. У `index.html` дописати рядок у блоці «ДАНІ ТЕМ», **перед** підключенням рушія:

```html
<script src="data/modal-verbs.js"></script>
```

Порядок цих рядків = порядок тем у бічному меню.

## Правила, які не можна порушувати

- **id кожної вправи унікальний у межах усього сайту**, не лише теми. По id зберігається
  прогрес у `localStorage`, тож два однакових id = дві вправи, які зараховуються разом.
  Безпечна схема: `ord_1_modals`, `gap_12_modals`.
- `level` — лише `"elementary"`, `"intermediate"` або `"advanced"`.
- `order`: `scrambled` має бути перестановкою слів із `answer` і не збігатися з ним.
- `choice`: значення `correct` має точно збігатися з одним із рядків у `options`.
- `abcd`: `correct` — це індекс (0–3), а не текст відповіді.
- `cross`: `extraIndex` — індекс зайвого слова в масиві `words`, нумерація з нуля.
  Після викреслення цього слова речення має стати правильним.
- `gap`: у `answers` перелічити **всі** допустимі форми (`["do not", "don't"]`).
  Апострофи, регістр, зайві пробіли й крапка в кінці нормалізуються автоматично.

## Налаштування рушія

На початку `js/engine.js`:

```js
const CUMULATIVE_LEVELS = true;
```

- `true` — рівень учня показує його вправи **і все, що нижче** (Advanced бачить усе).
- `false` — показуються вправи **рівно обраного** рівня.

## Прогрес

Зберігається в `localStorage` браузера під ключем `grammar_lab_v4_progress`.
Він локальний: не синхронізується між пристроями і не видимий викладачеві.
Кнопка «Скинути тему» очищає прогрес лише поточної теми.
