# Grammar Lab

Інтерактивний тренажер з граматики англійської: теорія українською, 5 типів вправ,
персональний доступ для кожного учня і кабінет викладача зі статистикою помилок.

Сайт — статичні сторінки на GitHub Pages. Дані, авторизація і права доступу — у Supabase.

## Структура

```
index.html              тренажер (вхід → теорія і вправи)
teacher.html            кабінет викладача
js/config.js            адреса Supabase і публічний ключ
js/api.js               усі запити до бази
js/engine.js            рендер вправ і перевірка відповідей
js/auth.js              вхід у тренажер
js/teacher.js           логіка кабінету
js/exercise-text.js     текстовий опис вправи для статистики
supabase/               SQL-скрипти та серверна функція
```

## Supabase: порядок розгортання з нуля

У SQL Editor, по черзі:

1. `01_schema.sql` — таблиці та правила доступу
2. `02_content_*.sql` — контент тем
3. `03_make_me_teacher.sql` — зробити свій акаунт викладачем
4. `04_attempts_delete_policy.sql` — хто може стирати історію спроб
5. `05_teacher_cabinet.sql` — захист ролі, email у профілях

Потім **Edge Functions → Deploy a new function → Via Editor**, назва `admin-users`,
вміст — `supabase/functions/admin-users/index.ts`. У налаштуваннях функції вимкнути
**Verify JWT with legacy secret** (функція перевіряє користувача сама).

## Як влаштований доступ

- Учень бачить лише теми, які відкрив викладач, теорію й вправи не вище призначеного рівня,
  і не бачить вправ, схованих для нього окремо. Це забезпечує база (RLS), а не інтерфейс:
  без входу запити повертають порожнечу.
- Персональні вправи — рядки `exercises` із заповненим `student_id`.
- Кожна перевірка відповіді пишеться в `attempts`. Учень не може стерти свою історію —
  це може лише викладач.
- Створення акаунтів і зміна паролів — через серверну функцію `admin-users`:
  службовий ключ існує лише всередині Supabase.

## Після зміни будь-якого js-файлу

Збільшити номер `?v=N` у тегах `<script>` в `index.html` і `teacher.html`.
Інакше браузер може віддати учневі стару версію з кешу.

## Обмеження, про які варто памʼятати

- Безкоштовний Supabase присипляє проєкт після тижня без звернень — перше відкриття після паузи повільне.
- Supabase віддає максимум 1000 рядків за запит; усі завантаження йдуть сторінками через `fetchAll` в `js/api.js`.
